參數矩陣（Parameter Matrix）

參數矩陣（Parameter Matrix）是「候選參數研究」。它把 parameter_domains 展開成多個候選， 每個候選都用同一段樣本回測。指標（metrics）、熱圖（heatmap）、群集（cluster）與候選檢視（candidate review）顯示參數區域。 參數矩陣不是前向分析（WFA），整段樣本的最佳解也不是樣本外（OOS）證據。

參數矩陣顯示整段資料的候選區域；前向分析（WFA）測試每段樣本內（IS）選出的參數在下一段樣本外（OOS）的表現。

參數矩陣（Parameter Matrix）

  • 一次展開所有候選參數。
  • 產生排名（ranking）、群集（cluster）、熱圖（heatmap）與候選檢視（candidate review）。
  • 用於尋找成片的高分區域，不只看單一最高分候選。
  • 不等於樣本外（OOS）穩健性證據。

前向分析（WFA）

  • 每個樣本內視窗（IS window）重新尋找當段最佳參數。
  • 樣本外（OOS）只測該視窗選出的最佳參數。
  • 用於檢查參數跨時間的表現與樣本外結果。
  • 候選網格（grid）可作診斷（diagnostics），但不能當作通過／失敗證據（pass/fail evidence）。

大型矩陣如何保存結果

候選較多或使用一分鐘資料時，系統會分批執行，避免一次把所有資金曲線、交易明細及圖表留在記憶體。每個候選仍有摘要、分數及排名；只有設定保留的前列候選會重播並保存完整資金曲線、交易和圖表產物。未被保留的候選沒有完整圖表，不代表回測失敗。

候選識別碼（candidate_id）使用 base_strategy_id:workflow_id:parameter_suffix；沒有參數時後綴為 fixed。排名、目標函數及完整產物必須使用同一識別碼。若前端找不到相符產物，應回報契約錯誤，不能改用第一個或相近候選。

哪些內容適合放進參數矩陣

技術指標週期簡單移動平均線（SMA）、動能（momentum）、相對強弱指數（RSI）、移動平均匯聚背離指標（MACD）等週期（period）。
日曆參數（Calendar parameters）星期幾（weekday）、序數（ordinal）、月份及事件日期規則。
配置候選多組配置設定範本（allocation profiles）、首幾名（top_n）及持倉上限（position limit）。
交易與風控結構綱要與操作（schema/op）接受 param_ref 的成本（cost）、滑價（slippage）或風控門檻（risk threshold）才可掃描；其他設定檔（config）欄位不能當成參數範圍（parameter domain）。

沒有參數範圍（No-domain）的正確解讀

固定策略如果沒有任何可調參數，例如固定 30/10/20/20/20 配置，系統應回傳 availability = "no_parameter_domain"，前端會提示「沒有參數矩陣」並引導你到回測詳情（Backtests）。 這不是錯誤，而是表示目前設定檔（config）沒有可展開的候選參數。

前端狀態 代表什麼 下一步
有熱圖／候選檢視（heatmap / candidate review） 策略有可調參數，參數矩陣已生成候選。 選取參數區域，並用前向分析（WFA）或滾動驗證（Rolling Validation）驗證。
沒有參數範圍（No parameter domain） 固定策略無可調參數。 看回測詳情（Backtests），或把配置改成多個配置設定範本（allocation profile）。
無法載入前端資料（Unable to load payload） 已保留候選的產物（artifact）或應用程式介面資料（API payload）未能載入，或候選識別碼不相符。 檢查候選識別碼、受管產物（managed artifacts）與應用程式介面資料（API payload）；不要改用另一候選。
