Aa

新手詞彙

開始前先懂四個詞

策略執行設定（strategy_run config）

一份可執行策略說明書，寫清楚資料、訊號、持倉、成交、成本、風控與回測方式。

執行中心（Run Center）

負責選設定檔（config）、開始工作、查看每個階段成功或失敗。

回測詳情與指標總覽（Backtests / Metrics Overview）

指標總覽比較多個策略。回測詳情顯示一個結果的交易、持倉、成本與風險證據。

前向分析（WFA）

前向分析（Walk-Forward Analysis）把歷史切成多段，以前段資料選參數，以後段資料測試。一般回測不會執行前向分析。

設定入口：strategy_run / wfa_run 計算引擎（Rust） 強制結果驗證器（Mandatory result validator） 前端服務：FastAPI 2424 + React

學習路線

1. 新手啟動

模組（Module）00 到 04：準備人工智能手冊（AI Manual）、安裝依賴、啟動平台、完成第一次回測。

2. 策略設計

模組（Module）03 到 06：理解 strategy_run、自然語言策略如何轉換成設定檔（config）、如何建立參數矩陣（Parameter Matrix）。

3. 報告閱讀

模組（Module）07 到 09 和實驗（Lab）05：閱讀指標總覽（Metrics Overview）、回測詳情（Backtests）、前向分析（WFA）、風控門檻（Risk Gate）與投資組合不變條件（Portfolio Invariant），並用績效分析（Performance Analysis）檢查可公開說法。

4. 擴充與未來

模組（Module）10 說明資料來源擴充；模組 11 說明可選因子診斷。未完成或尚未公開的功能不放入正式主線。

用戶可以學會什麼

1

用自然語言描述策略

例如「BTC 和 ETH 各自收盤價高於 50 日均線才持有」或「每個月第一個星期一開市交易QQQ，收市平倉」。

2

確認策略是否支援

人工智能（AI）會依手冊（Manual）回報支援（supported）、需要澄清（needs_clarification）或不支援（unsupported），不會編造功能。

3

生成與執行設定檔（config）

用 strategy_run 表達資料來源（provider）、資產範圍（universe）、計算欄位（computed_fields）、訊號（signals）、配置（allocation）、再平衡（rebalance）、成交模型（fill_model）、風控（risk）與參數範圍（parameter domains）。

4

閱讀報告與驗證穩健性

指標總覽（Metrics Overview）、回測詳情（Backtests）、參數矩陣（Parameter Matrix）、前向分析（WFA）和實驗（Lab）05 績效分析分別回答績效、風險、成本與資料健康問題。
