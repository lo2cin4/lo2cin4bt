模組 05

策略語義與策略組件（Strategy Building Blocks）

用戶可以用日常語句描述策略。人工智能（AI）要把概念拆成資料來源、指標、訊號、選股、配置、成交、風控及驗證規則，再核對每項規則是否有對應的策略組件（building block）。能力判斷（capability verdict）會說明策略可建立、需要補充資料，還是需要開發新組件。

三種能力判斷

能力判斷（capability verdict）意思下一步
支援（supported）現有結構綱要（schema）、操作（op）及執行器支援這項規則。寫設定檔（config）並驗證。
需要釐清（needs_clarification）概念可能受支援，但入場、出場、時間或資料定義有缺口。詢問會阻塞執行的資料。
需要新增策略組件（unsupported_needs_new_building_block）專案沒有對應可執行能力。先實作登錄表（registry）、Rust 執行環境（runtime）、結構綱要（schema）、黃金與對照測試（golden/oracle tests）及文件。

可組合內容

  • 資料與市場時間：資料供應者（provider）、行情週期契約（bar_time）、執行資料流（execution stream）、決策資料流（decision stream）、交易時段及資料可用時間（availability time）。
  • 計算：簡單移動平均線（SMA）、指數移動平均線（EMA）、相對強弱指數（RSI）、移動平均匯聚背離指標（MACD）、布林通道（Bollinger）、波動率、標準分數（Z-score）、滾動百分位數（rolling percentile）等已註冊操作（op）。
  • 決策：比較、交叉（cross）、日曆事件（calendar event）、選股（selection）、排名（ranking）及目標權重（target weights）。
  • 執行：下一時段、開市或收市價、成本、滑價、持倉中再次出現訊號時的政策。
  • 風控：最大持倉、曝險、回撤行動（drawdown action）、全部平倉（flatten）、永久停止（permanent stop）或影子交易路線（shadow route）。

多數新策略只需新增設定檔（config）。缺少執行能力時才新增策略組件（building block）；不可為策略家族新增另一條 Python 或 Rust 回測路徑。
