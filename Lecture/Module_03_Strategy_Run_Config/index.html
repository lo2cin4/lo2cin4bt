模組 03

統一策略執行設定（Strategy Run Config）

strategy_run 是人類與人工智能（AI）共用的策略輸入。用戶描述策略意圖，人工智能把規則寫入結構化設定檔（config）。檔名、顯示名稱與備註不能代替可執行規則。

共用規則策略設定範本（profile）提供不同設定檔（config）寫法。每份設定檔都會編譯成引擎請求（EngineRequest），再交給同一個 Rust 引擎。

必要資訊

部分所需內容
platformid、display_label、建立日期與用途。
data / universe資料供應者（provider）、資產代號（symbols）、正式時間契約（bar_time）、執行／決策資料流綁定（stream_binding）及比較基準（benchmark）。
computed_fields / signals指標如何計算、何時形成訊號、不能偷看未來。
selection / allocation如何選資產、目標權重、現金及持倉上限。
rebalance / fill_model何時檢查、何時成交、價格基準、成本與滑價。
risk風控觸發條件及觸發後的正式行動。
parameter_domains每份 strategy_run 都要有。單次回測使用空物件 {}；參數矩陣（Parameter Matrix）及需要搜尋參數的前向分析（WFA）使用非空範圍。

這個例子保留所有必填契約（contract）。建立策略時要以結構綱要（schema）、操作登錄表（op registry）及現有範例（examples）為準。人工智能（AI）不可自創設定檔（config）欄位。

行情週期如何決定訊號與成交

  • 執行資料流（execution stream）提供可成交的時間與價格；決策資料流（decision stream）提供策略判斷所用的行情棒。
  • 兩者可以相同，例如 Binance 一分鐘雙均線以一分鐘資料判斷及成交。
  • 兩者也可以不同，例如由一分鐘資料衍生五分鐘決策棒；五分鐘棒完成後才可形成訊號，並在下一個合資格的一分鐘價格成交。
  • 資料來源已有日線、週線或月線時，可以把該資料聲明為外部執行資料流；系統不要求所有週期都由一分鐘資料合成。
  • 交易時段、時區、夏令時間、半日市、未完成棒及資料可用時間均由行情週期契約（bar_time）聲明。任何未完成或尚未可用的資料都不能參與當下決策。

常用計算積木

計算欄位（computed_fields）會由上至下執行。每一列先產生一個名字，後面的列、訊號、選股與配置規則便可使用這個名字。

類別積木可以處理的研究問題
技術指標indicator.sma、indicator.ema、indicator.momentum、indicator.calendar_return趨勢、動能、最近完成月份回報、12-1 動能。
技術指標indicator.rsi、indicator.macd、indicator.atr、indicator.bollinger超買超賣、趨勢變化、波幅與價格通道。
統計指標indicator.volatility、indicator.zscore、indicator.percentile波動率、相對歷史平均的位置、滾動百分位。
數學運算math.add、math.subtract、math.multiply、math.divide把兩個欄位或欄位與常數組成研究公式。
數學整理math.negate、math.abs、math.clip改變正負號、取絕對值、限制極端值。
欄位轉換transform.lag、transform.fill_missing、transform.where延後資料、處理缺值、按條件選值。
滾動窗口rolling.min、rolling.max、rolling.sum、rolling.median、rolling.correlation只使用當前與過去窗口，計算極值、總和、中位數與相關性。
同期資產比較cross_section.rank、cross_section.percentile、cross_section.zscore、cross_section.winsorize在同一日期比較不同資產，完成排名、標準化與極端值處理。
例子：用積木寫出 B = (1 + r)W 
[
  {"name": "recent_1m_return", "op": "indicator.calendar_return",
   "source": "close", "sampling": "month_end", "start_lag": 1, "end_lag": 0},
  {"name": "momentum_12_1", "op": "indicator.calendar_return",
   "source": "close", "sampling": "month_end", "start_lag": 12, "end_lag": 1},
  {"name": "one_plus_recent_return", "op": "math.add",
   "source": "recent_1m_return", "value": 1.0},
  {"name": "adjusted_momentum_score", "op": "math.multiply",
   "source": "one_plus_recent_return", "right_source": "momentum_12_1"}
]

recent_1m_return 是最近完成月份回報 r，momentum_12_1 是 W。最後一列產生 B，選股規則只需按 adjusted_momentum_score 排名。

時間規則：使用收市資料計算的欄位，要等收市資料出現後才算已知。一般策略應在下一個可成交時點執行，不能把收市後才知道的結果放回同一個較早時點成交。
