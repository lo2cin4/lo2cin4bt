模組 11

可選因子診斷（factor diagnostics）

定位：factorhandler/ 與 statanalyser/ 是可選研究工具，不是正式回測、指標（metrics）或前端的必經步驟。

目前可以做甚麼

  • strategy_run.factor_pipeline 可描述因子資料處理。
  • factorhandler/ 可產生及匯出獨立因子研究產物。
  • statanalyser/ 可按用戶要求，對已生成資料做統計診斷。

它不代表甚麼

  • 目前沒有專屬 React 頁面；沒有診斷資料（diagnostic payload）時，應用程式介面（API）或教學回覆應標示「不適用（not applicable）」，不應令普通回測失敗。
  • 不能在沒有產物及測試證據時宣稱已支援 IC、Rank IC、Fama-MacBeth、VIF 或完整風險模型。
  • 影響持倉、成交及回報的因子計算，必須經共享 Rust 引擎（engine）與強制結果驗證器（mandatory result validator）。
  • 不可把這兩個 Python 研究模組重新插入所有策略的正式主線。
