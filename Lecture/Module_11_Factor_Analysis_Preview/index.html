因子分析預覽（Factor diagnostics）

目前定位： 舊有 strategy_run.factor_pipeline 及 Python factorhandler/ 已正式退休並 fail closed。

正式計算路線

  • 支援的動能、波動率及橫截面運算使用 computed_fields[] 描述。
  • 所有會改變回測結果的因子計算由 shared Rust engine 執行。
  • 不會自動映射舊 factor pipeline，也沒有 Python 或靜默後備路線。
  • 未支援的因子運算必須先新增經覆核的 Rust Strategy Building Block 及測試。

診斷層邊界

  • statanalyser/ 只可處理已驗證結果的可選診斷，不是回測或績效計算路線。
  • 正式輸出仍經 mandatory Rust result validator、Rust metrics 及 PlotBundle。
  • 舊 factor_pipeline.v1 schema 是拒絕所有實例的退休 tombstone。
