常見問題、術語表與發布檢查清單

常見問題

自然語言策略可以交給人工智能（AI）處理嗎？ 可以，前提是人工智能先讀 AI_MANUAL_SKILL.md，並輸出能力狀態（capability status）。

固定權重投資組合（portfolio）可以做前向分析（WFA）嗎？ parameter_domains 是空物件時可做滾動驗證（rolling validation）。結構綱要與操作（schema/op）及 param_ref 支援候選參數時，策略設定範本（profile）可進入前向分析，並不限於配置（allocation）。

富途／盈透證券（FUTU / IBKR）可以實盤交易嗎？ 程式庫（repo）證據只支援轉接器框架與閘道程式／套件要求，不支援把它說成完整實盤下單路由。

基本術語

術語說明
目標權重（Target Weight）策略想持有的資產權重，是記帳執行前的目標。
逐期記帳（Sequential Accounting）逐期處理現金、持倉、費用、換手率（turnover）、漂移（drift）及再平衡狀態。
行情週期契約（bar_time）聲明交易時段、時區、行情棒週期、時間戳、資料可用時間、價格處理及資料流來源。
執行資料流（execution stream）提供回測可成交的時間與價格；外部週期必須由資料來源支援。
決策資料流（decision stream）提供策略形成訊號的行情棒；可與執行資料流相同，或由共享 Rust 引擎按契約衍生。
參數範圍（Parameter Domain）參數矩陣（Matrix）與前向分析（WFA）的候選來源。
候選識別碼（candidate_id）以 base_strategy_id:workflow_id:parameter_suffix 配對候選摘要、排名、目標函數及完整產物；無參數時後綴為 fixed。
選定最優解（Selected Optimum）前向分析（WFA）在每個樣本內視窗（IS window）選出的策略（policy）。
樣本外（OOS）與樣本內配對的樣本外視窗（out-of-sample paired window）。
風控門檻（Risk Gate）最大持倉數（max positions）、最大訂單規模（max order size）、最大回撤（max drawdown）、最大單日虧損（max daily loss）等安全閘門；觸發後先全部平倉（flatten），再永久停止（permanent stop）或進入影子交易路線（shadow route）。影子交易是同一個共享 Rust 引擎內的明文風控狀態，不是後備回測器。

報告指標詞彙表（Report Metrics Glossary）

指標定義搜尋提示
總報酬（Total Return）整段回測累積報酬。最終資金曲線（equity）、累積收益。
年化複合成長率（CAGR）把累積報酬換算成每年複利增長。跨期間比較。
夏普比率（Sharpe）總波動風險調整報酬。報酬／波動。
最大回撤（Max Drawdown / MDD）最大歷史回撤。資金壓力。
日內最大回撤（Intraday Max Drawdown）以日內資金點計算的最大高點至低點跌幅。分鐘或小時策略在交易時段內承受的資金壓力。
卡瑪比率（Calmar）年化複合成長率除以最大回撤絕對值。回撤調整報酬（drawdown-adjusted return）。
比較基準報酬（Benchmark Return）比較基準（benchmark）的同期間報酬。買入持有比較（buy-and-hold comparison）。
超額報酬（Excess Return）策略相對比較基準的超額報酬。類似阿爾法比較（alpha-like comparison）。
年化波動率（Annualized Vol）報酬序列的年化波動。報酬變動程度（return variability）。
索提諾比率（Sortino）下行波動風險調整報酬。下行風險（downside risk）。
風險值 95／99（VaR 95 / VaR 99）95%／99% 信心水準的損失門檻估計。尾部門檻（tail threshold）。
條件風險值 95／99（CVaR 95 / CVaR 99）超過風險值門檻後的平均損失。預期短缺（expected shortfall）。
最差／最佳月份（Worst Month / Best Month）最差／最佳單月報酬。月度分布（monthly distribution）。
正報酬月份（Positive Months）正報酬月份數或比例。月度勝率（monthly win rate）。
勝率（Win Rate）獲利交易比例。交易命中率（trade hit rate）。
獲利因子（Profit Factor）總獲利除以總虧損絕對值。交易獲利品質（trade profit quality）。
平均獲利（Average Win）獲利交易平均收益。平均獲利交易（avg profitable trade）。
平均虧損（Average Loss）虧損交易平均損失。平均虧損交易（avg losing trade）。
平均盈虧比（Average Win/Loss）平均獲利相對平均虧損。回報比率（payoff ratio）。
總獲利（Gross Profit）累計獲利交易回報；不等於總報酬。獲利交易總和（sum of winners）。
總虧損（Gross Loss）累計虧損交易回報；不等於總報酬。虧損交易總和（sum of losers）。
最長連勝／連敗（Max Consecutive Wins / Losses）最大連勝／連敗交易數。連續風險（streak risk）。
比較基準相關性（Benchmark Correlation）策略報酬與比較基準的相關性。比較基準依賴（benchmark dependency）。
平均持倉（Avg Holdings）平均持倉數或持倉規模。投資組合廣度（portfolio breadth）。
平均曝險（Avg Exposure）平均市場曝險。現金與已投資資金（cash vs invested）。
平均交易換手率（Avg Trade Turnover）平均換手，衡量成本敏感度與穩定性。換手率與成本拖累（turnover, cost drag）。
檢查點／排定再平衡（Checkpoints / Scheduled Rebalances）排定的檢查或再平衡時點。排定機會。
有效再平衡（Active Rebalances）改變目標權重或交易的再平衡。實際變化。
目標持倉（Target Holdings）策略目標持倉。期望投資組合（desired portfolio）。
配置變化（Allocation Changes）權重變化歷史。輪動／漂移修正（rotation / drift correction）。
資產貢獻（Asset Contribution）各資產對投資組合報酬的貢獻。報酬歸因（return attribution）。
風控門檻稽核（Risk Gate Audit）風控門檻觸發紀錄。介入證據（intervention evidence）。
投資組合不變條件（Portfolio Invariant）記帳一致性檢查。現金 + 市值 = 權益。
資料健康（Data Health）資料完整性與載入狀態。資料品質優先（data quality first）。
有效起始日（Effective Start）可開始回測的日期。暖機期／重疊起點（warmup / overlap start）。
缺失資產（Missing Assets）請求但未成功載入的資產。資產範圍不符（universe mismatch）。
已載入資產（Loaded Assets）成功載入並可使用的資產。實際資產範圍（actual universe）。
成本拖累／交易成本欄位（Cost Drag / trade cost fields）成本、滑價、費用對績效的拖累或明細。成交擬真度（fill realism）。

不支援回覆模板（Unsupported template）

能力判斷：支援（supported）／需要釐清（needs_clarification）／不支援（unsupported）
專案證據：說明檔（README）、結構綱要（schema）、設定檔（config）、測試（tests）、輸出檔案
缺少資訊：資產範圍（universe）、資料供應者（provider）、行情週期契約（bar_time）、執行／決策資料流、比較基準（benchmark）、成交模型（fill_model）、風控（risk）
不支援部分：列出程式庫（repo）沒有證據的規則
下一步：改成可支援的回測設定檔，或列出開發範圍（scope）

發布檢查清單（Release checklist）

  • 人工智能手冊（AI Manual）與教學（Lecture）是否符合說明檔（README）與現行正式架構。
  • strategy_run 結構綱要章節（schema sections）、行情週期契約（bar_time）及資料流綁定是否變更。
  • Python 命令是否只使用 uv sync --locked 及 uv run --locked --exact。
  • 資料來源週期能力、資料品質停止規則及結構化錯誤是否有測試（tests）。
  • workspace/runs/、workspace/wfa/ 是否可讀。
  • 參數矩陣的沒有參數範圍（no-domain）、分批執行、全候選摘要及前列完整產物狀態是否正常。
  • 前向分析（WFA）的選定最優解、滾動驗證及候選產物配對是否分開。
  • 日內資金曲線、交易標記、交易時段日結年化指標及日內最大回撤是否有測試。
  • 舊產物缺少現行強制欄位時是否要求重新執行，而不是加入相容後備。
  • 風控門檻稽核（Risk Gate Audit）與投資組合不變條件（Portfolio Invariant）是否有測試（tests）。
  • 未完成或尚未公開的功能是否沒有放入教學主線。
