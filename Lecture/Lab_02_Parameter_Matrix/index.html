lo2cin4bt 課程實驗 02

實驗（Lab）02

參數矩陣

這個實驗（Lab）把參數範圍展開成候選回測。你會找出可交給前向分析（WFA）檢查的參數區域。參數矩陣不等於樣本外（out-of-sample）證明。

人工操作版

  1. 選擇 workspace/runs/ 內含非空 parameter_domains 的設定檔（config），並確認每個參數引用都由現行操作（op）支援；空物件只會產生無參數範圍（no-domain）狀態，不會展開候選
  2. 確認 platform.workflow_id 的值為 parameter_matrix
  3. 讀取 parameter_domains，確認參數、範圍和步長（step）
  4. 完成回測後打開參數矩陣（Parameter Matrix），查看目標函數（objective）、排名方式（ranking）、候選排名、群集（cluster）、穩定平台區（plateau）和參數重要性（parameter importance）
  5. 確認所有候選都有摘要及排名；只有保留的前列候選需要完整資金曲線、交易與圖表。選取完整結果時，候選識別碼（candidate_id）要與排名列相同
  6. 把候選區域交給前向分析（WFA）或其他驗證流程檢查

代理與技能版（Agent / Skill）

請由 lo2cin4btWorkAgent 使用 lo2cin4bt-strategy-builder
先檢查這份設定檔（config）是否有 parameter_domains。
再由同一個 lo2cin4btWorkAgent 使用 lo2cin4bt-backtesting
執行最小必要本機回測，輸出 run_id 和參數矩陣前端資料（parameter matrix payload）路徑。
不要把參數矩陣結果描述成未來績效承諾。
