開始使用與人工智能手冊（AI Manual）

lo2cin4bt 2.1.0 是以瀏覽器為主要入口的量化研究與回測工作區（workspace）。 用戶以結構化設定檔（config）描述策略。平台可執行單資產、多資產投資組合、 參數矩陣（Parameter Matrix）及前向分析（WFA）。

準備人工智能手冊（AI Manual）

人工智能（AI）要按程式庫（repo）規則工作，不能用一般量化知識補出專案沒有的功能。

  1. 把人工智能（AI）工作目錄指到程式庫（repo）根目錄，例如 lo2cin4bt。
  2. 讀取 agents/lo2cin4bt_PM.agent.md 和 skills/lo2cin4bt/SKILL.md。
  3. 由同一個 lo2cin4btWorkAgent 按任務讀取教學、策略建立、回測、驗收或績效分析技能（skill）。
  4. 任務資料包括 skills/lo2cin4bt/references/、docs/ai/AI_MANUAL_SKILL.md、設定檔（config）、測試（tests）與輸出檔案。
  5. 要求人工智能（AI）區分程式庫（repo）已實作內容、尚未開發內容、外部建議與人工智能推論。
  6. 若缺少資產範圍（universe）、資料供應者（provider）、頻率（frequency）、交易日曆（calendar）、比較基準（benchmark）、入場、出場、配置（allocation）、風控門檻（risk gate）或參數範圍（parameter domain），人工智能（AI）會列出缺口，不會編造。
請先閱讀 agents/lo2cin4bt_PM.agent.md 和 skills/lo2cin4bt/SKILL.md。
由 lo2cin4btWorkAgent 按任務載入 lo2cin4bt-teaching、lo2cin4bt-strategy-builder、lo2cin4bt-backtesting、lo2cin4bt-acceptance 或 lo2cin4bt-performance-analysis。
任何 repo 內沒有證據的內容，請標示為 AI 推論、外部建議或未來設計。
如果我描述的策略目前 lo2cin4bt 做不到，請列出缺口，不要強行寫 config。

代理與技能（Agent / Skill）分工

lo2cin4bt_PMlo2cin4bt-pm：讀需求、分派任務和守住邊界。
lo2cin4btWorkAgentlo2cin4bt-teaching：解釋安裝、頁面、術語和學習路線。
lo2cin4btWorkAgentlo2cin4bt-strategy-builder：核對資料、指標、訊號、選股、配置、成交、風控及驗證能力，交出能力判斷（capability verdict）和設定檔（config）草稿。
lo2cin4btWorkAgentlo2cin4bt-backtesting：處理本機回測、參數矩陣（Parameter Matrix）、前向分析（WFA）和執行中心（Run Center）問題。
lo2cin4btWorkAgentlo2cin4bt-acceptance：檢查輸出是否符合說明檔（README）、契約（contract）和公開邊界。
lo2cin4btWorkAgentlo2cin4bt-performance-analysis：用產物解釋績效、風險、交易、再平衡和前向分析（WFA）。

安裝與啟動

以下命令是程式庫（repo）內建路線。Python 或 Node.js 版本不同時，請按本機環境調整。

cd lo2cin4bt
python -m pip install -r requirements.lock
cd plotter/web
npm ci
npm run build
cd ../..
python main.py

打開平台

啟動後打開 http://127.0.0.1:2424/。執行中心（Run Center）會讀取 workspace/runs/ 與 workspace/wfa/。

外部閘道（gateway）

富途（FUTU）或盈透證券（IBKR）需要本機套件、閘道程式、主機與連接埠（host/port）及資料權限。設定檔（config）不能取代這些環境條件。

第一次使用順序

1

執行中心（Run Center）

選一份現有回測設定檔（Backtest config）。第一次操作不需要建立新策略。

2

指標總覽（Metrics Overview）

查看總報酬（Total Return）、年化複合成長率（CAGR）、夏普比率（Sharpe）、最大回撤（MDD）、卡瑪比率（Calmar）、比較基準（Benchmark）與資料健康（Data Health）。

3

回測詳情（Backtests）

查看資金曲線（equity）、配置變化（allocation changes）、目標持倉（target holdings）、資產貢獻（asset contribution）、風控門檻稽核（risk gate audit）與不變條件（invariant）。

4

參數矩陣（Parameter Matrix）／前向分析（WFA）

platform.workflow_id = parameter_matrix 且有非空參數範圍時會產生候選矩陣。前向分析（WFA）或滾動驗證（Rolling Validation）屬另一項工作。

前端入口

  • 執行中心（Run Center）：選擇回測與前向分析設定檔（Walk-Forward config）。
  • 指標總覽（Metrics Overview）：總覽總報酬（Total Return）、年化複合成長率（CAGR）、夏普比率（Sharpe）、最大回撤（MDD）及卡瑪比率（Calmar）。
  • 參數矩陣（Parameter Matrix）：檢查候選、排名（ranking）及沒有參數範圍（no-domain）狀態。
  • 回測詳情（Backtests）：閱讀投資組合證據（portfolio evidence）、風控門檻稽核（risk gate audit）、交易（trade）、再平衡及持倉（holdings）。
  • 前向分析（WFA）：閱讀選定最優解（selected optimum）的樣本外視窗（OOS window）、滾動驗證與投資組合證據（portfolio evidence）。
