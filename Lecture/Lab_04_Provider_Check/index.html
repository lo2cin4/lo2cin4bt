實驗（Lab）04

資料來源檢查

這個實驗檢查資料來源、資產代號（symbol）、頻率、交易日曆、時區與比較基準。資料條件不一致時，績效數字沒有解讀價值。

人工操作版

  1. 檢查 data.provider 是否為程式庫（repo）支援或已有範例路徑的資料來源（provider），例如雅虎財經（yfinance）、幣安（binance）、Coinbase 交易所（coinbase）、本地檔案（file）、富途（futu）或盈透證券（ibkr）
  2. 確認資產代號（symbol）格式符合資料來源，例如幣安（Binance）用 BTCUSDT，Coinbase 交易所常見 BTC-USD
  3. 確認 frequency、calendar、timezone 與策略假設一致
  4. 檢查比較基準（benchmark）欄位；多資產投資組合要寫出比較基準
  5. 若使用富途（FUTU）或盈透證券（IBKR），帳戶、應用程式（app）或應用程式介面（API）權限只用於讀取行情；登入與權限開通由使用者完成，本實驗不做下單、不操作資金

代理與技能版（Agent / Skill）

請由 lo2cin4btWorkAgent 使用 lo2cin4bt-backtesting 的執行前核對清單（Pre-Run Checklist）。
請檢查設定檔（config）的資料來源（provider）、資產代號（symbol）、頻率（frequency）、交易日曆（calendar）、時區（timezone）、比較基準（benchmark）、成本與滑價。
如果資料來源需要外部應用程式（app）、主機與連接埠（host / port）、權杖（token）或行情權限，請列為需要澄清（needs_clarification）。
不要下單，不要操作資金，不要做實盤交易。
若需要登入、開通行情應用程式介面（API）、主機與連接埠（host / port）、權杖（token）或行情權限，請列為需要澄清（needs_clarification），由使用者完成。
